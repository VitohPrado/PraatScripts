# Praat Duration Extractor

Script desenvolvido para automatizar a extração de atributos acústicos e temporais de arquivos de áudio em massa.

Este script automatiza o processamento de centenas de arquivos .wav e .TextGrid, reduzindo o tempo de coleta de horas para segundos.

Liste que ele gera um arquivo tabular contendo: duração de segmentos, sílabas, palavras, amplitude média/máxima e extração condicional de formantes em janelas percentuais.
