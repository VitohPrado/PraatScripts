# PraatScripts: Automação e Extração de Dados Acústicos 🎙️📊

Este repositório contém scripts desenvolvidos no Praat para automatizar o processamento e a extração de métricas de dados acústicos e de fala em larga escala. 

O foco destes projetos é a **Automação de Processos** e a **Engenharia de Atributos (Feature Engineering)**, transformando dados brutos de áudio não-estruturados em datasets tabulares prontos para análise estatística e modelagem em Python ou R.
